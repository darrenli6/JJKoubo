# 剪辑与包装工作流

完成转写后、制定剪辑计划前阅读本文件。

## 剪辑检查轮次

1. 通读整份转写，先理解论点和故事结构。
2. 标记完整观点、案例、过渡、前后呼应和预期收尾。
3. 标记可删除内容：纯停顿、纯气口、只含语气词的短句、废弃开头、自我纠正、重复词、重复句和备用版本。
4. 从完整素材中挑选钩子候选。
5. 确定最终口播顺序，再转换成原素材时间范围。
6. 每个剪辑边界前后至少带 0.5 秒上下文试听。

如果语气词承担犹豫、转折、亲切感或唯一过渡，不要机械删除。宁可保留稍慢但自然的句子，也不要做成音节破碎的高密度口播。

## 钩子选择

每个候选按以下五项分别打 0-2 分：

- 不依赖前文也能立即理解；
- 存在具体冲突、惊讶、反转或好奇；
- 与视频真正的核心回报高度相关；
- 对目标受众有情绪或现实利害；
- 大约三秒内能形成完整口语表达。

选择总分最高且真实的候选。若压缩到三秒会损害原意，允许钩子稍长。把钩子移动到开头后，用最短的自然上下文接回正文。除非刻意重复能增强论证，否则删除钩子原来的位置。

## 剪辑计划格式

使用绝对路径和秒数：

```json
{
  "source": "/absolute/path/input.MOV",
  "output": "/absolute/path/delivery/input_口播优化版.mp4",
  "segments": [
    {"start": 42.18, "end": 45.74, "note": "开头钩子"},
    {"start": 3.12, "end": 11.46, "note": "删除废话后的正文开头"}
  ]
}
```

可选渲染字段包括 `video_encoder`、`video_bitrate`、`audio_bitrate`、`output_frame_rate`、`preset`、`crf` 和 `drop_ranges`。只有需要在已拼接时间线上进行二次修正时才使用 `drop_ranges`。10-bit VideoToolbox HEVC 默认输出 30fps；必须交付 60fps 时使用软件 HEVC。

先按词级时间戳确定边界，再结合波形和试听微调。给开头辅音和结尾收音保留足够余量。除非是必要连接词，避免保留短于 0.25 秒的片段。

## 口播优化版复核

- 使用相同模型和语言重新转写整条口播优化版。
- 对照剪辑计划检查最终句子顺序。
- 搜索相邻重复词和近似重复句。
- 手动检查前五秒的钩子清晰度和音频连续性。
- 检查所有非时间顺序的接缝。
- 使用 `ffprobe` 确认时长、分辨率、帧率、音频流和音画同步。
- 生成联系表，快速检查视觉连续性。

## 色彩完整性

记录原素材与输出文件的编码、像素格式、色彩基色、传递函数、矩阵和范围。重新编码时延续这些信息。原素材未标记的字段应保持未知，不能靠猜测补写。

HyperFrames 下层视频只允许：

- 调整尺寸、`object-fit`、`object-position` 和构图所需的几何变换；
- 禁止 `filter`、`backdrop-filter`、混合模式、透明度变化、彩色罩层、带颜色的半透明遮罩，以及画布或视频纹理重绘；
- 使用口播优化版和包装成片中的同一帧进行对比；
- 人脸发白必须视为渲染失败，而不是审美选择。

## 动态字幕包装

默认采用上下结构：

- 上层：每次展示一个短语的动态宋体字幕区；
- 下层：稳定播放人物口播并保留原声；
- 画布：1080×1920；
- 根据人物构图和 `frame.md` 确定实际分区比例；
- 入场和短语切换必须支持任意时间点安全跳转；
- 只强调口播中真实出现且值得强调的词。

字幕必须简洁到能在手机上快速阅读。视频内不要出现操作说明、键盘快捷键或解释性界面文字。

## 字体与视觉规范一致性

包装视频与封面使用完全相同的本地字体声明：

```css
@font-face {
  font-family: "Songti SC";
  src: local("Songti SC");
  font-style: normal;
  font-weight: 400 900;
}
```

中文动态字幕和封面内容统一设置为 `font-family: "Songti SC", serif`，主要字幕和封面标题默认字重 700。结构性等宽标签可使用 `frame.md` 允许的字体。

如果用户提供其他字体或 `frame.md`，必须同时应用到视频和封面。每次改动后重新运行字体、布局和对比度检查。

## 交付验收

交付前必须满足：

- 口播优化版和包装成片都能打开，并同时包含视频和音频；
- 除非用户另有要求，9:16 输出必须为 1080×1920；
- 包装过程没有改变任何口播内容；
- 字幕没有溢出、遮挡或低对比度问题；
- 人物画面没有相对口播优化版发生色彩变化；
- 封面是独立的 1080×1920 PNG，并使用相同字体与视觉规范；
- 最终回复使用可直接展示的绝对本地路径。
